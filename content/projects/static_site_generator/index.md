## About

I have to confess, this is not the first time I developed a Static Site Generator. It is actually the second time, but the first time I did it in C++. The first time I developed a Static Site Generator, it was in Python which was quick and easy to do. But I wanted to challenge myself, so I did it again in C++ without the use of external libraries that would solve the problem instantly. I developed the templating and parsing logic (which was much more complicated than when I did it in Python).
