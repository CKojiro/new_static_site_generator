## About

I have to confess, this is not the first time I developed a Static Site Generator. It is actually the second time, but the first time I did it in C++. The first time I developed a Static Site Generator, it was in Python which was quick and easy to do. But I wanted to challenge myself, so I did it again in C++ without the use of external libraries to handle parsing and HTML generation.

This meant I had to implement the markdown parsing, HTML generation, and templating logic from scratch. Developing a static site generator in C++ rather than Python proved far more challenging, however it gave me the opportunity to work more deeply with object oriented design, polymorphism, regular expressions, and filesystem operations.
